# ฝึกพูดจีน (Chinese Speaking Game)

เกมฝึก "เปล่งเสียง" ภาษาจีนสำหรับคนไทย — ไฟล์ HTML ไฟล์เดียว ไม่มีเซิร์ฟเวอร์ ไม่มี API key
ข้อมูลความคืบหน้าทั้งหมดเก็บอยู่ในเบราว์เซอร์ของผู้ใช้เอง (localStorage)

- บทเรียน 1–52 + ชุดทริปกวางโจว + โหมดตอบโต้ + ฝึกวรรณยุกต์
- โหมดนึกเอง (เห็นคำไทย พูดจีนเอง) + ทบทวนแบบเว้นช่วง + ประกอบประโยคจากแพตเทิร์น

## ข้อกำหนด
ต้องเปิดผ่าน **https** และใช้ **Chrome / Edge** (บนคอม หรือ Android) เพราะใช้ Web Speech API
เปิดไฟล์ตรงๆ แบบ `file://` เบราว์เซอร์จะถามสิทธิ์ไมค์ซ้ำทุกครั้ง

## ย้ายความคืบหน้าข้ามเครื่อง
ตั้งค่า → 💾 บันทึกความคืบหน้าเป็นไฟล์ → เอาไฟล์ไปกด 📂 กู้คืนจากไฟล์ ที่เครื่องใหม่

## ติดตั้งเป็นแอปบนมือถือ
เปิด https://grandthing.github.io/chinese-speaking-game/ ด้วย Chrome แล้วกดการ์ด **📲 ติดตั้งลงหน้าจอโฮม**
บน iPhone ใช้ Safari → ปุ่มแชร์ → Add to Home Screen

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกมทั้งหมด (HTML/CSS/JS ไฟล์เดียว) |
| `manifest.webmanifest` | ข้อมูลแอปตอนติดตั้ง — ชื่อ ไอคอน สี โหมดเต็มจอ |
| `sw.js` | service worker — เปิดได้แม้เน็ตหลุด (แต่ระบบตรวจเสียงยังต้องใช้เน็ต) |
| `icon-*.png`, `apple-touch-icon.png` | ไอคอนแอป |
| `.nojekyll` | กัน GitHub Pages เอา Jekyll มาประมวลผลไฟล์ |

## อัปเดตเว็บ
แก้ `index.html` → commit → push → GitHub Pages สร้างใหม่ใน 1–2 นาที
ถ้าแก้แล้วยังเห็นของเดิม รอ ~10 นาที (GitHub Pages แคชหน้า HTML ไว้) หรือกด Ctrl+Shift+R
**ถ้าแก้ไฟล์แล้วอยากให้เครื่องที่ติดตั้งแอปไว้ได้ของใหม่แน่ๆ ให้เปลี่ยนเลข `V` ใน `sw.js` ด้วย**
