ไมโครโฟนถูกปิดอยู่

เกมยังเล่นได้ แต่จะไม่มีระบบตรวจเสียง วิธีเปิดสิทธิ์บน Chrome (Android):

  1. แตะไอคอน 🔒 หรือ ⓘ ข้างช่อง URL
  2. เลือก สิทธิ์ / Permissions
  3. เปิด ไมโครโฟน แล้วโหลดหน้านี้ใหม่

เครื่องนี้ยังไม่มีเสียงภาษาจีน

กดฟังต้นแบบแล้วจะเงียบ ต้องติดตั้งข้อมูลเสียงก่อน (Samsung / Android):

  1. ตั้งค่า → การจัดการทั่วไป
  2. ข้อความเป็นคำพูด (Text-to-speech)
  3. เลือกเครื่องมือ Google Text-to-speech → ⚙️
  4. ติดตั้งข้อมูลเสียง → 中文 (จีนกลาง) → ดาวน์โหลด
  5. กลับมาโหลดหน้านี้ใหม่
